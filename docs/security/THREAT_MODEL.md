# Početni threat model

Datum 2026-10-11. Granica: loopback Next.js + kratkotrajni RAM profil + lokalni SQLite access/quota/log ledger. Browser, JSON/body, invitation input, source text i modelski output su nepouzdani. Operator/OS ima lokalni pristup; njegova kompromitacija nije rešena auth cookie-jem. Ne tvrdi se produkciona bezbednost. [Dokazi](VERIFICATION.md), [osnova](SECURITY_PRIVACY_BASELINE.md).

| Pretnja / posledica                              | Implementirana kontrola                                                                                                                                         | Preostalo ograničenje                                                                                                                 |
| ------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| Pogađanje/curenje pozivnice                      | 256-bit random, hash u bazi, bounded uses/expiry/revoke, 20 attempts/min globalno, bez URL-a                                                                    | Ukraden važeći kod može potrošiti dozvoljenu upotrebu; owner fajl mora ostati privatan; fixed-window burst i globalni DoS nisu rešeni |
| Mešanje/tuđi profil                              | Cookie-only ID, strict body, neprihvatanje duplog cookie-ja, per-session memory, visible-program provera, revision/busy/late commit                             | Ukraden session cookie je bearer; local OS administrator nije izolovan; RAM ne podržava više app procesa/HA                           |
| Cross-site mutacije / framing                    | Origin/Host/Fetch-site guard, Strict cookie, CSP frame-ancestors none i DENY                                                                                    | HTTPS proxy/remote deployment nije testiran; localhost DoS ostaje moguć                                                               |
| XSS iz chat/source/modela                        | Text rendering, validated grounded output, nonce CSP, object/base/form restriction                                                                              | Inline styles su dozvoljeni, razvoj unsafe-eval; heuristika nije kompletna injection detekcija                                        |
| SSRF/alati/model permissions                     | Kontrolisani source/program IDs, bez modelskih URL fetch-a/alata/shell-a; fixed provider endpoint u zatvorenom adapteru                                         | Proširenje ingestion-a/URL-ova zahteva zaseban pregled                                                                                |
| API ključ/privatni log                           | Server-only, nema produkcionih tajni, strict log allowlist, tracing exclusions, safe errors                                                                     | Buduća konfiguracija/backups/OS ACL zahtevaju operativni pregled                                                                      |
| Nekontrolisana potrošnja, retry/parallel/restart | DB transaction reserve pre poziva, session/global hard caps, active hold, bounded output/timeout/retry, unknown charged, reset/delete ne resetuje globalni zbir | Live wiring nije otvoren; future pricing/guard integration mora se proveriti pre plaćenog pilota                                      |
| Race opoziv/delete/expiry                        | Active recheck pod SQL lock-om i pre memory commit-a; cleanup/atomic redeem                                                                                     | Jedan app proces za profil, bez distribuisane profilne sinhronizacije                                                                 |
| Zlonamerni PDF/lični podaci                      | Upload false, endpoint odbija, synthetic-only upozorenje, nema document processing-a                                                                            | Korisnik može pogrešno ukucati lični podatak; nema obećanja automatskog PII uklanjanja                                                |
| Obmanjujući retention                            | Implementiran startup/access/timer cleanup, tačno obaveštenje o izuzecima                                                                                       | Offline laptop odlaže cleanup, fizičko brisanje/backup nije potvrđeno                                                                 |
| Kvar storage-a                                   | SQLite locking i konzervativne rezervacije, pristup fail-closed, timer retry                                                                                    | Nema HA/backupa; korumpirana baza traži operatora, ne bypass kvota                                                                    |
| Zavisnosti/kompromitovan build                   | Pinovan lockfile, negativni boundary build i testovi, bez novih paketa                                                                                          | Ranije dokumentovano dependency audit/ESLint ograničenje nije ovim korakom proglašeno rešenim                                         |

Prioritet pre pravog pilota: nezavisan pregled transporta/OS pristupa/ledger integracije, odobren budžet i data/privacy tok, human katalog review, odgovorni operator i evals. Incident sa ključem, izolacijom, katalogom ili budžetom zaustavlja izdanje; lokalni operator opoziva invite, prekida server i proverava minimalnu evidenciju bez javnog deljenja kodova/logova. Koraci 11/12 ostaju zasebni nalozi.
