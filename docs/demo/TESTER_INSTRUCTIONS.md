# Instructions for invited adult reviewers

This exercise uses **fictional profiles and programmes** on the organiser's computer. Explanations are simulated. Please do not enter your own details, real documents or contact information. The interface is English-only. You can stop at any time.

## Start

The organiser opens the local app and privately gives a bounded invitation code. A 127.0.0.1 address works only on the computer running the app; it is not a remote invitation URL. Select the assigned Demonstration, enter Invitation code, confirm you are 18 or older and accept the notice only if you agree. Start demonstration.

Notice the staged questions before Review example details. Review the structured profile; use Answer … for a missing field or Edit … for an existing value. Save and Confirm these details. Important missing/unconfirmed answers or unresolved conflicts keep recommendations unavailable. Example loading is not NLP extraction of a real biography.

## Tasks

1. Bachelor: confirm 10000 EUR/year including living costs, Find programmes, explain why two fictional options appear. Edit Budget amount to 11000, save/confirm and search again.
2. Sources: View sources for a card; identify source ID, check date, fictional notice and next step. This evidence has no official university URL or human review.
3. Specialist task: master — completed CS bachelor/180 ECTS and Relevant subjects `Algorithms, Linear algebra`; or PhD — find what remains unknown about required funding before exploring the permitted alternative. Use [supplied profiles](DEMO_PROFILES.md), not your own background.
4. Boundary task assigned by the organiser: no-match, alternative/withdrawal, conflict or unavailable explanation. Describe what the app lets you do and why.

At most three options appear. Conditional permission is not a normal match or waiver of an institution's condition. “likely met” uses self-report; “unknown” is unresolved. An empty limited-catalogue result is valid. No admission probability or guarantee is given.

## Errors and finishing

PROFILE CONFLICT requires an explicit candidate choice. PROVIDER UNAVAILABLE offers Browse without explanation. RATE LIMITED means wait and retry once; don't repeatedly click. SESSION EXPIRED/BUDGET EXCEEDED means ask the organiser or use labelled recorded backup. Don't clear the ledger or request a quota bypass. Sessions last at most 30 minutes/40 messages, with additional action/token/day caps. PDF upload is disabled.

End and clear session after the exercise. In-app feedback is temporary and disappears with the session; it is not an automatically collected survey. Answer [the feedback template](FEEDBACK_FORM.md) verbally or via a separately agreed minimal-note process. Include no names, addresses, application IDs, invitation codes or document excerpts. Report any confusion between fictional and official facts.
