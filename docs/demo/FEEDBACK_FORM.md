# Synthetic review feedback template

**Blank template; no responses collected.** Before recording answers, the organiser must agree purpose, access, minimisation and retention. Don't publish or paste private answers into external tools. In-app feedback belongs only to the temporary local session.

- Anonymous exercise code: ______ (not a person/session token)
- Date / version: ______ / phase1-demo-1
- Fictional profile IDs: ______
- Mode: live local / recorded backup / both
- Permission to record minimal exercise notes under the explained process: yes / no
- No name, email, birth date, real institution/application, transcript or invitation code.

## Reviewer questions

1. Which task did you complete? What assistance did you need?
2. What made the next step clear or confusing?
3. Show one evidence item. Is it fictional or official? What does its date mean?
4. Which conditions remain unknown or only likely met? Did anything sound too certain?
5. What happens above a hard budget? Does permission change the budget or institutional rules?
6. What did you do with no-match, conflicting answers or unavailable explanation?
7. What single verification step would you take next in a real, separately reviewed application?
8. Would you try a future reviewed version: yes / no / unsure? Give a nonpersonal reason.
9. Most important improvement: ______

## Observer fields

Task success: yes / partial / no. Content assistance: none / some / substantial. Source understanding: correct / uncertain / incorrect. Constraint understanding: correct / uncertain / incorrect. Approximate duration: ______. Redacted point of confusion: ______. Critical issue: none / suspected disclosure / fabricated fact / rule bypass / uncontrolled cost / other safety issue.

Separate UI bug, catalogue gap, misunderstanding and unverified institutional claim. Report successes/actual attempts and assistance. Intent is not paying demand; recorded-backup completion is not live success; a blank template is not completed research.
