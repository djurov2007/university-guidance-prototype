# Obrazac beleški razgovora / posmatranog zadatka

Verzija: 1.0, 2026-10-05. Ovo je prazan obrazac za kasniju upotrebu, ne zapis održanog intervjua. Napraviti zasebnu belešku tek nakon stvarnog razgovora i dozvoljenog načina čuvanja; ne unositi stvarne lične podatke u javni repozitorijum. Vodič: [INTERVIEW_GUIDE](INTERVIEW_GUIDE.md). Merenje: [PROTOTYPE_ACCEPTANCE](../PROTOTYPE_ACCEPTANCE.md).

## Osnovni kontekst

| Polje | Popuniti nakon stvarnog razgovora |
| --- | --- |
| ID razgovora | INT-___; bez imena, email-a, broja telefona ili identifikacionih dokumenata. |
| Datum / trajanje | [datum], [minuti]. |
| Vrsta razgovora | Problem interview / concept walkthrough / observed prototype task; izabrati stvarno izvedeno. |
| Nivo i okvir | UG / MA / PhD; Srbija/EU; aktivni kandidat ili retrospektivno iskustvo. |
| Punoletni kriterijum | Učesnik potvrdio 18+ / nije dozvoljen tok; bez datuma rođenja ili kopije dokumenta. |

| Materijal / verzija | Pisani koncept, synthetic profile ID ili stvarna verzija prototipa/kataloga; bez claim-a da softver postoji ako je korišćen papir. |
| Uticaj uzorka | Bliski krug / van kruga; relevantna oblast i moguća pristrasnost, bez nepotrebnog identiteta. |

## Dodatno za posmatrani prototipski zadatak

Ovaj deo označiti **NOT TESTED** za problem intervju bez aplikacije. Za pisani koncept koristiti „concept only“, ne softverski PASS.

| Mera | Zapis |
| --- | --- |
| Zadatak i očekivani ishod | [konkretan cilj + poznati hard uslovi; verzija profila/kataloga] |
| Stvarni ishod | Match / conditional / no-match / needs-information / error / nije testirano. |
| Završio bez pomoći u sadržaju | Da / ne / nije testirano; pomoć oko pristupa odvojiti. |
| Vreme do smislenog koraka | [minuti, način merenja; ne procenjivati kao precizno merenje] |
| Pomoć voditelja | [šta/koliko puta, da li je promenila odluku] |
| Razumeo izvor i nepoznato | Da / delimično / ne / nije testirano; sopstveno objašnjenje korisnika. |
| Poštovana ograničenja / kritična greška | [AC-ID, tačan događaj, dokaz ili nije testirano] |
| Konkretan korak može sam da objasni | Da / delimično / ne; verna parafraza. |
| Pokrivenost i prepreka | [katalog gap / user info / institucionalni uslov / nepouzdan izvor / servis; ne spajati uzroke] |

## Zaključak i praćenje

- Najvažniji konkretan problem: [popuniti].
- Moguća promena proizvoda i dokaz: [US/AC/S ID, zapis događaja, preporuka ili „nema dovoljno dokaza“].

- Vlasnik naredne provere: [dogovorena osoba ili „nije dodeljen“].
- Eventualni follow-up: [samo dogovorena svrha/dozvola; kontakt se čuva odvojeno].
- Pristup/čuvanje/brisanje ove beleške: [stvarno dogovorena politika i odgovorna osoba, bez nemogućih obećanja].
- Status beleške: [DRAFT / REVIEWED; ne proglašavati korisničku hipotezu potvrđenom zbog jednog razgovora].

Ne popunjavati ovaj obrazac pretpostavljenim odgovorima. Ako je pitanje preskočeno ili nije postavljeno, to eksplicitno označiti. Ne objavljivati citat ili slati sadržaj spoljnim servisima bez odgovarajućeg dogovora.
