# Contributing

Thank you for your interest in the project.

The repository is currently published for inspection and portfolio demonstration. External code contributions and pull requests are not being accepted unless the repository owner has invited them in writing.

You may use GitHub issues for concise product feedback or reproducible bug reports. Do not include personal data, API keys, invitation codes, private programme documents or vulnerability details. Report security issues through the process in [SECURITY.md](SECURITY.md).

Public visibility and feedback channels do not grant permission to use, copy, modify, distribute, deploy or create derivative works from the project. See [LICENSE](LICENSE).
